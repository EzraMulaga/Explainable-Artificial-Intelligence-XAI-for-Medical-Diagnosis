The Challenge

Why Explainability Matters in Healthcare

Machine learning models can match or exceed clinical accuracy, yet they are rarely adopted in practice. The barrier is trust — and trust requires understanding why a model reaches a conclusion.

🔒

Black-Box Models

Deep neural networks and complex ensembles offer high accuracy but provide no inherent justification for their outputs, making them unsuitable for high-stakes clinical decisions.

🏥

Clinical Trust

Clinicians will only act on a model's recommendation if they can audit its reasoning. Opaque predictions risk being overridden — or worse, blindly followed.

⚖️

Regulatory Compliance

Healthcare AI is subject to strict regulation. Explainable outputs allow institutions to document decision rationale and comply with medical device and data-protection standards.

💡

Our Solution

This project pairs a Random Forest classifier with SHAP to deliver both predictive accuracy and transparent feature-level reasoning for medical diagnosis.

System Architecture

Four-Stage Processing Pipeline

Raw patient vital-sign data flows through preprocessing, model training, inference, and explainability — each stage handled by a dedicated module.

1

Data Preprocessing — preprocessing.py

Loads the raw CSV of patient vitals, imputes missing values using column medians (numeric) and column modes (categorical), encodes the multi-class status label, and applies a MinMaxScaler fitted only on the training split to prevent data leakage.

2

Model Training — model.py

Trains two independent RandomForestClassifier models on an 80/20 stratified split: one binary classifier for diagnosis (Positive/Negative) and one multi-class classifier for patient status (Stable / At Risk / Critical).

3

Inference — prediction.py

Accepts a single patient dict or a full DataFrame, scales input features using the saved scaler, and returns diagnosis label, status label, and per-class probability vectors for both models.

4

Explainability — explainability.py

Runs a SHAP TreeExplainer over both models to compute Shapley values. Generates a global beeswarm summary plot of feature importance across the test set and a per-patient waterfall plot showing each feature's directional contribution to the prediction.

Explainability

How SHAP Makes Predictions Transparent

SHAP (SHapley Additive exPlanations) is rooted in cooperative game theory. Each feature is treated as a "player" whose contribution to the final prediction is measured by averaging its marginal effect over all possible subsets of features.

For tree-based models like Random Forest, the TreeExplainer algorithm computes exact Shapley values in polynomial time — fast enough to explain every prediction in the test set.

Two types of explanation are generated:

  • Summary plot — shows which features drive predictions globally across all patients.
  • Waterfall plot — shows why the model gave a specific patient a specific score.
